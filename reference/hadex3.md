# HadEX3 Climate Extremes Dataset

Functions to download and process the Met Office HadEX3 global climate
extremes dataset based on ETCCDI indices.

## Usage

``` r
.HADEX3_ANNUAL_INDICES
```

## References

Dunn et al. (2020) Development of an updated global land in-situ-based
dataset of temperature and precipitation extremes: HadEX3. J. Geophys.
Res. Atmos. https://doi.org/10.1029/2019JD032263
