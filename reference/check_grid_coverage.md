# Check grid coverage statistics for polygons

Check grid coverage statistics for polygons

## Usage

``` r
check_grid_coverage(grid_data, polygons, polygon_id_cols = NULL)
```

## Arguments

- grid_data:

  Data frame with longitude and latitude columns

- polygons:

  sf object with polygon geometries

- polygon_id_cols:

  Column names to identify polygons

## Value

List with coverage statistics
