# Build HadEX3 download URL

Build HadEX3 download URL

## Usage

``` r
.hadex3_url(index, frequency, baseline = "61-90")
```

## Arguments

- index:

  ETCCDI index name (e.g. "TXx").

- frequency:

  "annual" or "monthly".

- baseline:

  Baseline period: "61-90" or "81-10" (annual only).

## Value

Character URL.
