# Build CRU TS download URL for a specific decade file

Build CRU TS download URL for a specific decade file

## Usage

``` r
.cru_ts_url(variable, decade_start, decade_end)
```

## Arguments

- variable:

  CRU TS variable code.

- decade_start:

  Start year of the decade file.

- decade_end:

  End year of the decade file.

## Value

Character URL.
