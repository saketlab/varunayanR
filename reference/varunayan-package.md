# varunayan: Package for downloading and processing climatic variables from ERA5 and IMD

R package for downloading and processing ERA5 climate data, IMD (Indian
Meteorological Department) gridded data, and HadEX3 global climate
extremes (ETCCDI indices) for custom geographical regions. Provides
functions to extract climate data using bounding boxes, GeoJSON
polygons, or point coordinates and calculate heat indices. Supports
various temporal frequencies and spatial resolutions with analysis-ready
outputs.
