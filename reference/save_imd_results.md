# Save IMD results to CSV

Save IMD results to CSV

## Usage

``` r
save_imd_results(data, request_id, var_type, resolution, frequency, output_dir)
```

## Arguments

- data:

  data.frame with processed data

- request_id:

  Request identifier

- var_type:

  Variable type

- resolution:

  Resolution

- frequency:

  Frequency

- output_dir:

  Output directory
