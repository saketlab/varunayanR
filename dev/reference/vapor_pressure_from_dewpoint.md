# Calculate vapor pressure from dewpoint temperature

Calculate vapor pressure from dewpoint temperature

## Usage

``` r
vapor_pressure_from_dewpoint(dewpoint_c)
```

## Arguments

- dewpoint_c:

  Dewpoint temperature in celsius

## Value

Vapor pressure in hPa (hectopascals)

## Examples

``` r
vapor_pressure_from_dewpoint(20)
#> [1] 23.36947
```
