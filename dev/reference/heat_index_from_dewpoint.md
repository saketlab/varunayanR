# Calculate heat index from dewpoint

Calculate heat index from dewpoint

## Usage

``` r
heat_index_from_dewpoint(temp_c, dewpoint_c)
```

## Arguments

- temp_c:

  Air temperature in celsius

- dewpoint_c:

  Dewpoint temperature in celsius

## Value

Heat index in celsius

## Examples

``` r
heat_index_from_dewpoint(35, 25)
#> [1] 43.31715
```
