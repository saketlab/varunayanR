# Populate cache with sample IMD data

Copies sample IMD data files to cache for offline testing.

## Usage

``` r
PopulateSampleCache(...)

populate_sample_cache(force = FALSE)
```

## Arguments

- ...:

  Arguments passed to the main function (used by aliases).

- force:

  Overwrite existing cached files (default: FALSE)

## Value

List of cached files (invisible)
