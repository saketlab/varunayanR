# Filter NetCDF data by GeoJSON polygon

Filter NetCDF data by GeoJSON polygon

## Usage

``` r
filter_netcdf_by_geojson(netcdf_file, geojson_file)
```

## Arguments

- netcdf_file:

  Character string path to NetCDF file

- geojson_file:

  Character string path to GeoJSON file

## Value

data.frame with spatially filtered data
