# Extract data for specific point location (nearest neighbor)

Extract data for specific point location (nearest neighbor)

## Usage

``` r
extract_point_data(netcdf_file, target_lat, target_lon)
```

## Arguments

- netcdf_file:

  Character string path to NetCDF file

- target_lat:

  Target latitude

- target_lon:

  Target longitude

## Value

data.frame with data for nearest point
