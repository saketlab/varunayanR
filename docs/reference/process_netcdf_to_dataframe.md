# NetCDF processing functions for ERA5 data Process NetCDF file and extract data as data.frame

NetCDF processing functions for ERA5 data Process NetCDF file and
extract data as data.frame

## Usage

``` r
process_netcdf_to_dataframe(netcdf_file)
```

## Arguments

- netcdf_file:

  Character string path to NetCDF file

## Value

data.frame with processed climate data
